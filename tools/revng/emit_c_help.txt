Usage: revng quick artifact emit-c [OPTIONS] BINARY -- [PIPEBOX ARGS...]

  Note: All arguments after '--' are passed to the pipebox initialize
  function.

Options:
  Wrappers:                 Run program(s) wrapped inside one of the specified
                            wrappers
    --perf                  Run program(s) under perf (for use with hotspot).
    --heaptrack             Run program(s) under heaptrack.
    --gdb                   Run program(s) under gdb.
    --lldb                  Run program(s) under lldb.
    --valgrind              Run program(s) under valgrind.
    --callgrind             Run program(s) under callgrind.
    --rr                    Run program(s) under rr.
    --wrapper WRAPPER       Run program(s) with the specified wrapper.
  -o FILE                   Path to write the computed artifacts to, if not
                            specified, the result will be printed to stdout.
                            The default output format is 'auto' (see
                            --format).
  --debug RUNNER_CONTEXT    Run the command in debug mode with the specified
                            directory (it will be created if missing). Where
                            possible the pipes and analyses will be run as
                            subcommands via `run-pipe` and `run-analysis` with
                            input and output files in subdirectories in the
                            specified directory.
  --analyses TEXT           Instead of running the default initial auto
                            analysis, run the specified list of (comma-
                            separated) analyses
  --yaml                    Shortcut for --format=yaml.
  --tar                     Shortcut for --format=tar.
  --format [auto|tar|yaml]  Format to use for the output container, either on
                            stdout or in the result path.  [default: auto]
  --help-full               Show help with hidden options and exit.
  --help                    Show this message and exit.
