## What this does and does not establish

It establishes that a definition site and its body *evidence* exist for a function: the direct callees, data symbols and string tokens referenced by the machine code are found in the candidate body.
It does not establish a byte-identical commit, the original compiler flags, object-code equality, or that the tree is the exact revision that produced this ELF. Those need per-function compile and compare with GCC 4.4.3 (`tools/compare/gcc443_*`).
